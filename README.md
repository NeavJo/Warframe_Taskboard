# Warframe Taskboard

> 以**任务看板**与**攻略收集**为核心的 Warframe 玩家多合一工具包。

还在为每天忘记做日常、每周漏掉周常、查攻略要在多个网站间反复切换而烦恼？Warframe Taskboard 把这些需求整合到一个轻量级 Web 应用中，以奥罗金暗色科幻美学呈现，让你既高效又沉浸地管理你的 Tenno 日常。

---

## 核心功能

### 任务看板
- **每日日常** 与 **每周周常** 双面板并排展示
- 任务**拖拽排序**（左侧手柄拖动），管理模式下可编辑/删除
- 完成/未完成状态自动统计，进度条可视化
- **自动重置**：每日 0 点重置日常、每周指定工作日重置周常（仅未完成项重置）
- 自定义任务图标、强调色（金/蓝/黄三色系）

### 定时提醒
- 添加带日期时间的提醒项，支持"X 小时后"快捷设置
- 到达预定时间后卡片**自动激活**并发出脉冲发光动画
- 点击激活的卡片即可标记完成
- 提醒超时 30 分钟未处理则**自动清理**

### 仲裁任务
- 基于轮换调度表实时显示当前仲裁节点与倒计时
- 今日高价值仲裁（S/A+ 评级）突出展示
- 未来 12 小时仲裁列表预览
- **一键添加提醒**：每日自动将高价值仲裁添加为临时提醒，不再错过

### 便签
- 创建多张便签卡片，每张含标题、颜色主题、事项列表
- 事项支持勾选/取消，进度条自动更新
- 编辑器内支持拖拽排序事项
- 勾选事项时增量更新 DOM，无闪烁

### 市场查价
- **物品搜索**：中文/英文双向模糊匹配自动补全，支持别名（如"毒妈"→ Saryn Prime）
- **实时价格**：连接 Warframe Market 官方 API v2，查询在线卖单
- **价格统计**：底价、众数（建议价）、切尾均价(5%)、在线卖家数
- **报价交互**：点击任一报价可切换选中卖家，"复制白金私聊"跟随选中卖家
- **收藏功能**：收藏常用物品（最多 6 个），一键跳转查价，数据随导出/导入同步
- **缩略图**：部件使用 SVG 占位符，Mod 显示中空卡片，遗物显示篮球图标

### 内置浏览器
- 默认打开**灰机 Wiki**，方便查阅中文攻略
- 其他站点（如官方 Wiki、市场）以**新标签页**方式跳转，不打断当前工作流
- 内置 URL 输入栏、刷新、首页按钮

### 设置与同步
- **JSON 导出/导入**：含看板任务、提醒、便签、市场收藏的完整数据
- **云端同步**：通过 GitHub Gist 实现跨设备同步（需配置 Token + Gist ID）
- **仲裁自动提醒开关**：控制每日是否自动添加仲裁提醒
- 纯本地存储（localStorage），无需账号

## 设计亮点

- **奥罗金美学**：深灰/黑底色 + 金色/蓝色/电磁黄色三强调色，呼应 Warframe 视觉语言
- **发光交互**：导航触发按钮带脉冲发光，激活提醒卡片带呼吸动画，完成徽章带金色光晕，结果卡片带流光扫过
- **拟物质感**：所有按钮和卡片使用 CSS clip-path 契形边框 + 金属渐变 + 碳纤维纹理
- **响应式自适应**：
  - 桌面端（≥900px）：顶栏 + 左侧栏 + 双栏看板
  - 移动端（<900px）：抽屉式侧边栏 + 单栏 Tab 切换
  - 手机竖屏（<480px）：紧凑间距适配小屏
- **跨浏览器滚动条美化**：自研 WebKit/Firefox 双引擎滚动条样式

---

## 技术栈

- **HTML5 / CSS3 / 原生 JavaScript（ES6+）**
- **零构建工具**：无 Webpack/Vite，开箱即用
- **零运行时依赖**：仅引入 Google Material Icons 字体
- **本地存储**：基于 `localStorage` 持久化所有数据
- **图片缓存**：IndexedDB 缓存市场物品缩略图
- **SPA 架构**：单页应用，7 个页面视图切换不刷新

## 快速开始

### 本地运行
1. 克隆或下载本项目
2. 进入 `wf-taskboard-web/` 目录
3. 运行 `dev-server.bat`（推荐，带 CORS 代理支持），或用任意 HTTP 服务器：

```bash
# 使用开发服务器（推荐，支持市场查价功能）
dev-server.bat
# 浏览器访问 http://localhost:8082/

# 或使用 Python 简易服务器（市场查价 API 需绕过 CORS）
python -m http.server 8080
```

> 注意：Warframe Market 查价功能需要代理服务器（`dev-server-proxy.py`）来绕过 CORS 限制，直接双击 `index.html` 或使用纯静态服务器时该功能不可用。

### 使用说明
1. 打开应用后默认进入"看板"
2. 点击右上角"管理"按钮可新增、编辑、拖拽排序任务
3. 切换到"提醒"页添加定时提醒
4. 切换到"仲裁"页查看当前仲裁任务
5. 切换到"便签"页创建待办清单
6. 切换到"市场"页查价
7. 切换到"浏览器"查阅攻略
8. 切换到"设置"配置云端同步或导出/导入数据

## 项目背景

本项目最初为 Flutter 应用（Windows .exe + Android .apk 双端），后迁移至 Web 平台以扩大可访问性。Web 版在保留原有看板核心功能的基础上新增了提醒、仲裁、便签、市场查价、浏览器等功能模块，整体体积约 2MB（含全量 JSON 数据）。
